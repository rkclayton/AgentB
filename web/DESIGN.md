
**What this is.** An instrument for watching a machine think. Its relatives are the oscilloscope, the spectrum analyzer and the mixing console: a dark display recessed into a mid-grey chassis, lamps that mean something, numbers that tick. Not a dashboard, not a chat app with charts. Everything is quiet except the signal path, which is where boldness is spent: execution is drawn as a trace that travels a wire and lights the node it reaches.

**Never by default:** cream background with serif and terracotta; uniform near-black with an acid accent; newspaper hairline columns; identical rounded cards with the same shadow; tracked-out caps eyebrow labels; middle-dot meta strings; arrows appended to button text; monospace for every small label; gradients.

**Palette — six values, everything else derived with alpha; never add a seventh hex.**
- Bezel `#2A2E35` — the chassis: page background, header, composer.
- Well `#15181C` — recessed display surfaces: panel bodies, code, the chat log.
- Ink `#D8DDE3` — primary text.
- Mute `#7D8794` — secondary text; at 28% alpha it is the only hairline.
- Trace `#F2B233` — amber phosphor; live state only: the active node, the traveling trace, the streaming caret, the meter's fill edge, the focus ring.
- Alarm `#E4624F` — stop button, errors, ceiling breach, cycle detected.
Colour carries state, never identity. Budget categories are Ink at 90/75/60/45/30% opacity with 1px Well gaps and labels beneath; the reserve zone is a 45° hatch of Mute at 30%. Button surface = Ink at 8% over Well; hover = 12%; pressed = 16%.

**Type.** IBM Plex Sans for UI text, labels, prose, captions. IBM Plex Mono for code, message bodies, tool arguments and every number, with `font-variant-numeric: tabular-nums`. Sizes 12 / 13 / 14 / 18 only; weights 400 and 500 only; line-height 20px (16px at size 12). Sentence case everywhere; letter-spacing 0; no caps labels; no eyebrows; numbering only where content is a sequence (timeline turn numbers). Fallbacks: `system-ui` and `ui-monospace, "Cascadia Mono", Consolas, monospace`. The four latin 400/500 WOFF2 files are vendored under `assets/fonts/` with their SIL OFL license, so builds never fetch fonts or require a package registry.

**Surfaces.** Panels are wells set into the bezel: `background: var(--well); box-shadow: inset 0 1px 0 rgba(0,0,0,.6);` radius 2px; no outer shadow anywhere; no borders except the single hairline. Grouping is alignment and one hairline, never a box. New regions are wells added to the grid, never cards.

**Layout.** Fixed viewport: `height: 100dvh; overflow: hidden` on body. The Console uses a 12-column grid with 8px gutters and the 4/8/12/16/24/32 spacing scale. Text is left-aligned, numbers are right-aligned, and captions align to panel content. Panel captions are 13px Plex Sans 500 with a bare count or state in Mute.

**Application header (36px, bezel):** no duplicate product mark or wordmark. Console session tabs occupy the left side; Chat uses its compact session/status readouts. The same right-aligned controls appear on both views: a 24px Alarm octagonal stop sign, a read-only 24px operator-mode status button using the supplied on/off artwork, Chat, Console, settings cog. The current view is selected. Settings is an icon button, never a text link. Edge app mode retains its separate compact native title bar with the operating system's minimize, maximize/restore, and close controls. A true installed-PWA host may instead use Window Controls Overlay; the application header is already declared as its drag region and stays clear of the system controls.

**Session tabs (inside the Console header):** one tab per session, in creation order: label (Plex Sans 13px 500), server label (12px Mute), status word (idle / queued / running / paused / stopped) with `turn/max` while running, an 8×8 lamp (Mute at 35% idle; Trace running; Mute breathing while queued; Alarm after an error stop or when the profile is not runnable), and a 2px budget line along the tab's bottom edge (used/ceiling, Ink at 60%; Trace above 85%). Tabs are Bezel; the active tab is Well. A `+` text button ends the strip; a close glyph appears on hover. Identity is carried by label and position, never by colour. No tab-switch animation.

**Budget rail (28px, full width under the header; shows the active session):** a level meter. Category segments left to right in fixed order system, memory, tools, history, files, results, fetched, summary; hatched reserve at the right end; 1px Trace tick at the ceiling. Right side, Plex Mono: `22,418 / 40,960` (measured used / ceiling) and `cached 21,900` — the cached readout is **omitted entirely** when the profile cannot report it; never show a zero that looks like a cache miss. Above 85% of ceiling the fill's leading edge turns Trace; above 100% the rail's outline turns Alarm. Labels beneath each segment at 12px Mute, hidden when a segment is narrower than its label. **Estimated state:** a category the server could not measure exactly is drawn as an outline (1px Ink at 45%, transparent interior) instead of a fill, its number carries a `~` prefix, and the caption reads "context (estimated)"; an estimate must look like an estimate, and still look like an instrument.

**Activity:** a plain ordered list generated from the server's stage names. Each row has one 8×8 square lamp and a short label. Idle is Mute at 35%, completed-this-turn is Ink at 60%, active is Trace, and a dispatch failure is Alarm. The active model row may show only its measured prefill count or generation rate. There are no wires, inferred branches, travel animation, or explanatory empty state.

**Context:** the chronological messages supplied to the model, one compact row each: human role, content preview, token count. There are no category tabs and no synthetic schema row. A row expands in place to its content and thinking when selected.

**History:** chronological turns and exceptional run events. A turn row shows turn, elapsed time, input/output tokens, and finish state. Nested tool rows show a humanized tool name, key path/pattern/command, elapsed time, and Done/Failed. Rows expand to the original diagnostics; approvals remain actionable in place.

**Tool rack:** one row per tool: lamp, name (Plex Mono 13px), call count right-aligned, on/off toggle (a 28×16 switch: Well track, Ink knob, Trace track when on); toggles are per session and the rack shows the active session's. Rows are generated from the server's tool list; disabled rows are Ink at 45%. A tool's lamp is Trace while it executes.

**Chat view (`/chat?session=<id>`).** This is the default installed-application view, bound to one session. Its compact application header uses the shared control order above; a plain session `<select>` appears when the URL does not bind one. A persistent Alarm strip immediately below reports service-identity fallback when present; operator mode is represented only by the header status button. A 4px budget line follows the optional alarm (used/ceiling; Trace above 85%, Alarm above 100%). One message well is the only scroll region, with a bezel composer at the bottom. A 48px speaker column (you / agent, 12px Mute; `assets/agent.svg` above the agent word); user text in Plex Sans 14px; agent text streamed with a 2px Trace caret at its end; reasoning collapsed to one line with a token count; tool activity as 20px one-line ticks (name in Plex Mono, key argument, then ok/error and ms), expandable in place. Enter sends, Shift+Enter inserts a newline; the send button reads "Stop" during a run.

**Motion.** Rows expand over 120ms and the rail's segments shrink over 160ms when compaction removes tokens. Stage lamps switch instantly. There are no entrance animations, hover lifts, travel paths, or skeleton loaders.

**Scrolling.** The body never scrolls. Each well is its own scroll region (`overflow: auto; scrollbar-gutter: stable;` thin scrollbars in Mute at 40%). Lists auto-follow while the user is within 24px of the bottom, detach when scrolled up, and show a "Jump to latest" pill (Ink on Well, no arrow glyph) bottom-right of the well until re-attached. Keep at most 300 entries mounted; older entries collapse into one row "earlier: N entries" that expands in pages of 100.

**Settings page.** Settings is a same-window, full-page application view below the Console header; Escape or the close control returns to Console. A fixed left navigation selects Connections, Sessions, Tools, Memory, Context, Run & approval, Security, or Current session. Field edits remain staged across sections until the operator selects Save (or presses Ctrl+S); validation and save errors stay visible in Alarm text. Security actions show their blocker, running state, and persistent result inline. Windows may display its required OS-level UAC consent surface for local-account setup or host protection. There are no toasts or application modals.

**Principles for anything not covered.** 1) Colour is state — amber is now, red is stopped or wrong, nothing else gets hue; identity (tool, category, session) is label, position and luminance. 2) Motion is information — something moves only because execution moved. 3) Numbers are instruments — live, tabular, right-aligned, against their ceiling, updated in place; rates carry units; an estimate looks like an estimate; no toasts. 4) Recess, don't raise — wells not cards, alignment not boxes, no shadows.

**Copy.** Plain verbs, sentence case: "Send", "Stop", "Reset session", "Jump to latest". Status words: idle, queued, running, paused, stopped, replay. Errors say what happened and what to do, in the interface's voice, without apologizing. Empty states invite an action.

**Assets.** Three swappable SVG slots referenced by path only: `assets/mark.svg` (24×24), `assets/agent.svg` (20×20, chat), `assets/idle.svg` (96×96). Placeholders are simple geometric marks in Mute; never inline artwork into markup.
