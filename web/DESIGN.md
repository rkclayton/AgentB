
**What this is.** An instrument for watching a machine think. Its relatives are the oscilloscope, the spectrum analyzer and the mixing console: a dark display recessed into a mid-grey chassis, lamps that mean something, numbers that tick. Not a dashboard, not a chat app with charts. Everything is quiet except the signal path, which is where boldness is spent: execution is drawn as a trace that travels a wire and lights the node it reaches.

**Never by default:** cream background with serif and terracotta; uniform near-black with an acid accent; newspaper hairline columns; identical rounded cards with the same shadow; tracked-out caps eyebrow labels; middle-dot meta strings; arrows appended to button text; monospace for every small label; gradients.

**Palette — six values, everything else derived with alpha; never add a seventh hex.**
- Bezel `#2A2E35` — the chassis: page background, header, composer.
- Well `#15181C` — recessed display surfaces: panel bodies, code, the chat log.
- Ink `#D8DDE3` — primary text.
- Mute `#7D8794` — secondary text; at 28% alpha it is the only hairline.
- Trace `#F2B233` — amber phosphor; live state only: the active node, the traveling trace, the streaming caret, the meter's fill edge, the focus ring.
- Alarm `#E4624F` — stop button, errors, ceiling breach, cycle detected.
Colour carries state, never identity. Budget categories are Ink at 90/75/60/45/30% opacity with 1px Well gaps and labels beneath; the reserve zone is a 45° hatch of Mute at 30%. Button surface = Ink at 8% over Well; hover = 12%; pressed = 16%.

**Type.** IBM Plex Sans for UI text, labels, prose, captions. IBM Plex Mono for code, message bodies, tool arguments and every number, with `font-variant-numeric: tabular-nums`. Sizes 12 / 13 / 14 / 18 only; weights 400 and 500 only; line-height 20px (16px at size 12). Sentence case everywhere; letter-spacing 0; no caps labels; no eyebrows; numbering only where content is a sequence (timeline turn numbers). Fallbacks: `system-ui` and `ui-monospace, "Cascadia Mono", Consolas, monospace`. The four latin 400/500 WOFF2 files are vendored under `assets/fonts/` with their SIL OFL license, so builds never fetch fonts or require a package registry.

**Surfaces.** Panels are wells set into the bezel: `background: var(--well); box-shadow: inset 0 1px 0 rgba(0,0,0,.6);` radius 2px; no outer shadow anywhere; no borders except the single hairline. Grouping is alignment and one hairline, never a box. New regions are wells added to the grid, never cards.

**Layout.** Fixed viewport: `height: 100dvh; overflow: hidden` on body. 12-column grid, 16px gutters, 8px spacing scale (4/8/12/16/24/32). Text left-aligned; numbers right-aligned; captions left-aligned to the panel content edge; nothing centered except node labels. Panel caption: 13px Plex Sans 500, Ink, with the panel's key count in Mute to its right (e.g. "State  23 messages").

**Header (44px, bezel):** mark (`assets/mark.svg`), wordmark "Agent_b" in Plex Sans 500 14px; right-aligned: stop button (acts on the active session; Alarm 1px outline + Alarm text at rest; fills Alarm with Well text on hover; the only red at rest) and a settings button (icon only, Ink at 60%). Run id, status and turn live in the tabs, not the header.

**Tab strip (32px, bezel, under the header):** one tab per session, in creation order: label (Plex Sans 13px 500), server label (12px Mute), status word (idle / queued / running / paused / stopped) with `turn/max` while running, an 8×8 lamp (Mute at 35% idle; Trace running; Mute breathing while queued; Alarm after an error stop or when the profile is not runnable), and a 2px budget line along the tab's bottom edge (used/ceiling, Ink at 60%; Trace above 85%). Tabs are Bezel; the active tab is Well, with no bottom edge, so it reads as continuous with the surface below — the recess principle covers this; invent nothing else. A `+` text button ends the strip; a close glyph appears on hover. Identity is carried by label and position, never by colour. No tab-switch animation.

**Budget rail (28px, full width under the tab strip; shows the active session):** a level meter. Category segments left to right in fixed order system, memory, tools, history, files, results, summary; hatched reserve at the right end; 1px Trace tick at the ceiling. Right side, Plex Mono: `22,418 / 40,960` (measured used / ceiling) and `cached 21,900` — the cached readout is **omitted entirely** when the profile cannot report it; never show a zero that looks like a cache miss. Above 85% of ceiling the fill's leading edge turns Trace; above 100% the rail's outline turns Alarm. Labels beneath each segment at 12px Mute, hidden when a segment is narrower than its label. **Estimated state:** a category the server could not measure exactly is drawn as an outline (1px Ink at 45%, transparent interior) instead of a fill, its number carries a `~` prefix, and the caption reads "context (estimated)"; an estimate must look like an estimate, and still look like an instrument.

**Flow (hero):** an SVG racetrack. Nodes are 8×8 square lamps (radius 1px) with 13px labels to their right; wires are 1.5px Mute. Top row left to right: assemble, call model, parse, dispatch, execute; return wire along the bottom to append and back to assemble; a branch down from parse to wait user. A short wire leaves execute toward the tool rack. Lamp states: idle = Mute at 35%; active = Trace; done-this-turn = Ink at 60%. While in call model the lamp breathes (opacity .55→1, 1.6s ease-in-out, infinite) and readouts sit under the node in Plex Mono 12px: prefill progress (`prefill 2,184 / 3,120`) and `31 tok/s` when the profile reports them; elapsed seconds only (`4.2 s`) when it doesn't. The node list comes from the server (seven stages: assemble, call model, parse, dispatch, execute, append, compact; compact sits on the return wire) and the layout is computed from the list, so a stage added later needs no drawing code. Empty state (no run yet): `assets/idle.svg` centered with the line "Send a task to start the loop." in Mute.

**Tool rack:** one row per tool: lamp, name (Plex Mono 13px), call count right-aligned, on/off toggle (a 28×16 switch: Well track, Ink knob, Trace track when on); toggles are per session and the rack shows the active session's. Rows are generated from the server's tool list; disabled rows are Ink at 45%. A tool's lamp is Trace while it executes.

**Chat window (`/chat?session=<id>`).** The same instrument, quieter, bound to one session: a 40px header (mark, wordmark, the session label — a plain `<select>` styled Well/Ink when the page was opened without a session parameter — status word, stop), a 4px budget line beneath it (used/ceiling; Trace above 85%, Alarm above 100%), one message well that is the only scroll region, and a bezel composer at the bottom. A 48px speaker column (you / agent, 12px Mute; `assets/agent.svg` above the agent word); user text in Plex Sans 14px; agent text streamed with a 2px Trace caret at its end; reasoning collapsed to one line with a token count; tool activity as 20px one-line ticks (name in Plex Mono, key argument, then ok/error and ms), expandable in place. Enter sends, Shift+Enter inserts a newline; the send button reads "Stop" during a run.

**Motion — one orchestrated moment.** When execution moves from one stage to the next, a 6px Trace dot travels the wire (`offset-path`, 260ms, ease-in-out) and the destination lamp fills on arrival. Sheets open with a 160ms translate; rows expand with a 120ms height transition; the rail's segments shrink over 160ms when a compaction removes tokens. Everything else is instant, including tab switches. No entrance animations, no hover lifts, no skeleton loaders. Under `prefers-reduced-motion` the dot is skipped and lamps switch instantly.

**Scrolling.** The body never scrolls. Each well is its own scroll region (`overflow: auto; scrollbar-gutter: stable;` thin scrollbars in Mute at 40%). Lists auto-follow while the user is within 24px of the bottom, detach when scrolled up, and show a "Jump to latest" pill (Ink on Well, no arrow glyph) bottom-right of the well until re-attached. Keep at most 300 entries mounted; older entries collapse into one row "earlier: N entries" that expands in pages of 100.

**Settings sheet.** A well that slides in from the right edge, 420px wide, Bezel background with a single hairline on its left, 160ms translate; Escape or the gear closes it. Groups in fixed order — Servers, Sessions, Tools, Memory, Context, Run, Shell, Session — each a caption (13px 500) and rows of label + control on one line; values in Plex Mono. A profile expands in place (120ms) to its fields, its test state remains visible, and each idle session exposes its runnable-profile selector; nothing opens a second page or an application modal. Windows may display its required OS-level UAC consent surface for local-account setup. Validation errors sit under the field in Alarm text; there are no toasts anywhere in this product.

**Principles for anything not covered.** 1) Colour is state — amber is now, red is stopped or wrong, nothing else gets hue; identity (tool, category, session) is label, position and luminance. 2) Motion is information — something moves only because execution moved. 3) Numbers are instruments — live, tabular, right-aligned, against their ceiling, updated in place; rates carry units; an estimate looks like an estimate; no toasts. 4) Recess, don't raise — wells not cards, alignment not boxes, no shadows.

**Copy.** Plain verbs, sentence case: "Send", "Stop", "Reset session", "Jump to latest". Status words: idle, queued, running, paused, stopped, replay. Errors say what happened and what to do, in the interface's voice, without apologizing. Empty states invite an action.

**Assets.** Three swappable SVG slots referenced by path only: `assets/mark.svg` (24×24), `assets/agent.svg` (20×20, chat), `assets/idle.svg` (96×96). Placeholders are simple geometric marks in Mute; never inline artwork into markup.
