
**What this is.** An instrument for watching a machine think. Its relatives are the oscilloscope, the spectrum analyzer and the mixing console: a dark display recessed into a mid-grey chassis, lamps that mean something, numbers that tick. Not a dashboard, not a chat app with charts. Everything is quiet except the signal path, which is where boldness is spent: execution is drawn as a trace that travels a wire and lights the node it reaches.

**Never by default:** cream background with serif and terracotta; uniform near-black with an acid accent; newspaper hairline columns; identical rounded cards with the same shadow; tracked-out caps eyebrow labels; middle-dot meta strings; arrows appended to button text; monospace for every small label; gradients.

**Palette — six values, everything else derived with alpha; never add a seventh hex.**
- Bezel `#2A2E35` — the chassis: page background, header, composer.
- Well `#15181C` — recessed display surfaces: panel bodies, code, the chat log.
- Ink `#D8DDE3` — primary text.
- Mute `#7D8794` — secondary text; at 28% alpha it is the only hairline.
- Trace `#F2B233` — amber phosphor; live state only: the active node, the traveling trace, the streaming caret, the meter's fill edge, the focus ring.
- Alarm `#E4624F` — stop button, errors, ceiling breach, cycle detected.
Colour carries state, never identity. Budget categories are Ink at 90/75/60/45/30% opacity with 1px Well gaps and labels beneath; the reserve zone is a 45° hatch of Mute at 30%. Button surface = Ink at 8% over Well; hover = 12%; pressed = 16%.

**Type.** IBM Plex Sans for UI text, labels, prose, captions. IBM Plex Mono for code, message bodies, tool arguments and every number, with `font-variant-numeric: tabular-nums`. Sizes 12 / 13 / 14 / 18 only; weights 400 and 500 only; line-height 20px (16px at size 12). Sentence case everywhere; letter-spacing 0; no caps labels; no eyebrows; numbering only where content is a sequence (timeline turn numbers). Fallbacks: `system-ui` and `ui-monospace, "Cascadia Mono", Consolas, monospace`. The four latin 400/500 WOFF2 files are vendored under `assets/fonts/` with their SIL OFL license, so builds never fetch fonts or require a package registry.

**Surfaces.** Panels are wells set into the bezel: `background: var(--well); box-shadow: inset 0 1px 0 rgba(0,0,0,.6);` radius 2px; no outer shadow anywhere; no borders except the single hairline. Grouping is alignment and one hairline, never a box. New regions are wells added to the grid, never cards.

**Layout.** Fixed viewport: `height: 100dvh; overflow: hidden` on body. Console normally uses a dense lifetime register: named-agent selector, per-tool rows, lifetime rows, closed chats, then its two destructive maintenance actions. It switches to the existing 12-column live-instrument grid only while the selected agent's viewed chat is running, queued, paused, or stopping. The live grid keeps 8px gutters and the 4/8/12/16/24/32 spacing scale: Activity spans eight columns beside the four-column Tool rack; Context spans five columns beside seven-column History. Text is left-aligned, numbers are right-aligned, and captions align to panel content. Panel captions are 13px Plex Sans 500 with a bare count or state in Mute.

**Application header (36px, bezel).** `web/js/shell.js` is the only owner of header controls and renders the same two slots for Chat, Console, and Plan: Agent tabs at left and page switch plus Settings at right. Tabs shrink to a 72px minimum; extras collapse into the `+N` menu at the strip's end. The strip never scrolls horizontally. Version, signature, run state, Stop, and identity controls are absent here. Edge app mode retains its native window controls, and Window Controls Overlay keeps its reserved system region clear.

**Controls contract.**

| Slot | Contents, in fixed order |
| --- | --- |
| LEFT | `agent_b`, configured `agent_c`, enrolled `agent_a`, then `+` |
| MIDDLE | `<agent name> · <chat name> · <bound directory>` |
| RIGHT | `Stop` · `<state>` · operator mode · `Chat` · `Console` · `Plan` · Settings |

A control stays in one slot on every page. A purposeless control collapses without reordering the others; Stop never collapses and acts only on the selected chat. Selection is one shared `{agent_id, session_id}` object and switching it never affects a run. Global controls live in Settings; page-local repair controls live in the page body.

**Agents and role tabs.** A named Agent object binds role `b` to its active profile, optional role `c` to a local worker, optional role `d` to a future planner slot, plus one ordered toolset and an operator-authored prompt addendum. `agent_a` is reserved for later enrollment and cannot be used as an Agent name. Everything left of the header's page switch and Settings controls belongs to the horizontally scrolling role-tab strip: `agent_b` first, then configured `agent_c` and `agent_d`; names never ellipsize. The configured Agent name is durable in `session.created` through `agent_id`, while assistant labels are only `agent_b` or `agent_c`; the Chat title line keeps the Agent name. Each tab's glyph is Mute `○` when idle, Trace `●` when running or queued, and Alarm `!` when waiting for the operator. Right-click opens a dense newest-first overlay of that role's open and closed chats in the established chat-row format, with New chat, Open, Close, and inline Rename actions. There is no `+`; adding an Agent belongs to Settings. User rename pins; auxiliary auto-rename may update an unpinned chat every 20 model turns.

**Budget rail (28px, full width under the header; shows the active session):** a context-occupancy meter. Segments run left to right as system prompt, tool schemas, tool results (`files` + `results` + `fetched`), history (`history` + `summary`), workspace memory, agent memory, free, and hatched reserve at the right end; a 1px Trace tick marks the boundary between free and reserve. Each memory layer is independently capped by the configured memory budget. The compact legend beneath reports every segment's percentage in Plex Mono tabular figures. Right side, Plex Mono: `22,418 / 40,960` (current categorized occupancy / ceiling) and `cached 21,900` — the cached readout is **omitted entirely** when the profile cannot report it; never show a zero that looks like a cache miss. Above 85% of ceiling the fill's leading edge turns Trace; above 100% the rail's outline turns Alarm. **Estimated state:** a category the server could not measure exactly is drawn as an outline (1px Ink at 45%, transparent interior) instead of a fill, its percentage and occupied-token readout carry a `~` prefix, and the caption reads "context occupancy (estimated)"; derived free space is estimated whenever any source category is estimated. An estimate must look like an estimate, and still look like an instrument.

**Activity:** a plain ordered list generated from the server's stage names. Each row has one 8×8 square lamp and a short label. Idle is Mute at 35%, completed-this-turn is Ink at 60%, active is Trace, and a dispatch failure is Alarm. The active model row shows measured prefill progress, or seconds since the last stream chunk, estimated live reasoning tokens, and estimated recent token rate. Replay labels its final reasoning and rate explicitly as recorded. There are no wires, inferred branches, travel animation, or explanatory empty state.

**Context:** the chronological messages supplied to the model, one compact row each: human role, content preview, token count. There are no category tabs and no synthetic schema row. A row expands in place to its content and thinking when selected.

**History:** chronological turns and exceptional run events. Consecutive single-call turns using the same tool collapse by default into one row with call count and the range of a varying argument; intervening compaction rows stay ordered inside its expansion, while another tool or exceptional event ends the group. A failed child makes the collapsed group Alarm and reports the failure count. Expanding a group shows the individual call rows, each independently expandable to its original diagnostics. Ungrouped turn rows show turn, elapsed time, input/output tokens, and finish state. Tool rows show a humanized tool name, key path/pattern/command, elapsed time, and Done/Failed. Approvals remain actionable in place. The caption reports retained turn count plus compaction count and cumulative token effect; each compaction row shows before, after, delta, and affected-item count.

**Tools:** the live Tool rack keeps one row per tool used in the selected session: lamp, name (Plex Mono 13px), and call count right-aligned. A tool's lamp is Trace while it executes. Console's lifetime register shows every registered tool for the selected named Agent as `toggle · name · calls · fail % · last used`; the toggle edits that Agent's toolset, invalidates its prefix cost once, and applies on the next turn and to new chats. Tool selection is never a Settings control.

**Console lifetime view.** The named-Agent selector drives every row. Lifetime JSON is versioned, additive, stored outside session logs at `stats/<agent-id>.json`, and never sent to a model. Agent and profile rows report chats, runs, turns, tool activity, approval/grant counts, compactions, tokens/cache, wall/model latency, first/last use, and the six worker-reliability counts; until Plan exists, the UI states that one brief equals one run. Closed-chat rows use the established dense format and `×` first previews exact event, JSONL-file, byte, and tagged-memory counts. Confirmation deletes only that session's JSONL generations, registry entry, and projector cache; evidence archives, workspace files, exchange copies, and aggregate stats remain. Tagged memory is a separate opt-in. `Clear all stats` and `Flush memory` are verified-operator, body-local actions with explicit confirmation and no model-addressable tool.

**Stop states.** Stop follows only the viewed chat. Active is Alarm red; the first press durably records `run.stopping {reason:"safe"}`, changes to Trace amber, cancels every in-flight request or child process immediately, and holds queued messages. A second press targets the same cancellation immediately and records `run.stopping {reason:"emergency"}`. Completion records `run.stopped` with the same reason; held messages dispatch only after a later explicit Send. Replay reconstructs stopping, stopped, and held without enabling Stop.

**Chat view (`/chat?session=<id>`).** This is the default installed-application view, bound to the shared selection's open chat. Chat lifecycle lives under the agent tabs: the right-click list uses `<relative time> · <first user line> · <n> run(s) · <state glyph>`, and Close remains durable metadata that refuses a running session while retaining its log, messages, files, memory, profile, and tool selection. With no selected open chat the composer, title, and budget rail consume zero space and the message well becomes the launch screen; without a runnable Agent it uses the existing robot glyph and links directly to Connections in Settings. A 4px budget line follows the Agent title. One message well is the only scroll region, with a bezel composer at the bottom. The composer is exactly five 20px lines by default, has no placeholder, uses the full flexible width, and expands upward on request; its small enter glyph sends from the textarea's bottom-right, with Stop immediately beside it. The entire Chat window is the drop target and gains one subtle Trace border only during an actual file drag. At rest the composer has one small paperclip; its menu offers `Browse…` and `From exchange folder`. Pending files are compact inline chips beside that glyph and reserve no vertical space when absent. Paste behavior is unchanged. Assistant rows use `agent_b`; aux-produced notices use `agent_c`. User text is Plex Sans 14px; agent text is streamed with a 2px Trace caret at its end; reasoning collapses to one line with a token count; tool activity is a 20px one-line tick (name, key argument, ok/error, duration), expandable in place. A fenced code block alone has a faint, absolutely positioned paperclip copy glyph at top-right; it copies code bytes without the language marker or line numbers. Prose-only messages and whole messages have no copy control. Successful file writes and user attachments render compact square-cornered filename/size rows with plain download and open-folder actions; missing replay files say `missing` and offer neither action. Enter sends and Shift+Enter inserts a newline.

**Approval and status lifecycle.** A reserved palette-only strip immediately above Chat's composer carries run state, `queued (n)`, model availability, operator-mode expiry, the per-chat Run-as-you robot, and the pending-decision line. Operator-mode and queue transitions never render as agent-authored Chat rows. The one actionable card is pinned immediately above that strip and reserves no space when absent; its historical row remains in the transcript. Active-run messages queue in order. A cycle guard pauses there with `You’re repeating — continue or stop?` after two consecutive identical calls or a third identical call. Stop is page-local beside Chat's enter glyph, at the bottom of Plan, and at the bottom of Console's live instruments; all three follow the viewed chat.

**Motion.** The queued/call-model lamp breathes, the Chat streaming caret blinks, and a completed compaction gives the context rail one 160ms pulse. Rows, stage lamps, and live numbers update instantly. There are no entrance animations, hover lifts, travel paths, or skeleton loaders.

**Scrolling.** The body never scrolls. The app never shows a horizontal scrollbar. Each well owns only vertical overflow (`overflow-y: auto; overflow-x: hidden; scrollbar-gutter: stable;` thin scrollbars in Mute at 40%), with long content wrapping or clipping according to its content contract. Lists auto-follow while the user is within 24px of the bottom, detach when scrolled up, and show a "Jump to latest" pill (Ink on Well, no arrow glyph) bottom-right of the well until re-attached. Chat keeps at most 300 entries mounted and expands its "earlier: N entries" row in pages of 100. The Console timeline keeps 300 entries mounted and uses a non-interactive earlier-count row; JSONL replay is the path to older diagnostics.

**Settings page.** Settings is a same-window, full-page application view below the Console header; Escape or the close control returns to Console. Its fixed left navigation contains install-global configuration only: Connections, Workspace policy, Context defaults, Run & approval, Delivery, Security, and About. Agent toolsets, session controls, and memory flushing live on Console. Field edits remain staged across sections until the operator selects Save (or presses Ctrl+S); validation and save errors stay visible in Alarm text. Security actions show their blocker, running state, and persistent result inline. Windows may display its required OS-level UAC consent surface for local-account setup or host protection. There are no toasts or application modals.

**Setup (`/setup`).** The first-run connection guide is a centered Well and is also reachable from Settings. Its initial three mandated setup choices are flat, square-cornered selection rows in a three-column grid, not raised dashboard cards; at narrow widths they stack. Each subsequent step keeps one task, one short explanation, its fields or detected facts, and visible Back/Skip actions. Capability results use plain rows and words. Hardware, local-server, and interpreter detection is factual; the memory-class recommendation names its table version. Setup adds no decorative motion, and reduced-motion makes every duration 0ms.

**Principles for anything not covered.** 1) Colour is state — amber is now, red is stopped or wrong, nothing else gets hue; identity (tool, category, session) is label, position and luminance. 2) Motion is information — something moves only because execution moved. 3) Numbers are instruments — live, tabular, right-aligned, against their ceiling, updated in place; rates carry units; an estimate looks like an estimate; no toasts. 4) Recess, don't raise — wells not cards, alignment not boxes, no shadows.

**Copy.** Plain verbs, sentence case: "Send", "Stop", "Browse…", "From exchange folder", "Jump to latest". Status words: idle, queued, running, paused, stopping, held, stopped, replay. Errors say what happened and what to do, in the interface's voice, without apologizing. Empty states invite an action.

**Assets.** Three swappable SVG slots referenced by path only: `assets/mark.svg` (24×24), `assets/agent.svg` (20×20, chat), `assets/idle.svg` (96×96). Placeholders are simple geometric marks in Mute; never inline artwork into markup.
